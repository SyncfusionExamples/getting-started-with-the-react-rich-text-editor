# getting-started-with-the-react-rich-text-editor
A quick-start project that demonstrates how to get started with the Syncfusion React Rich Text Editor in a React application. This project includes examples of installing and configuring the Rich Text Editor, customizing the toolbar, adding HTML elements such as tables, images, and links, and retrieving formatted content.

# Refer to the following documentation to learn about the React rich text editor component: 
https://help.syncfusion.com/rich-text-editor-sdk/react/rich-text-editor/getting-started

# Check out this online example of the React Rich Text Editor component: 
https://ej2.syncfusion.com/react/demos/#/tailwind3/rich-text-editor/tools

# Project prerequisites
Make sure that you have the compatible versions of Visual Studio Code and NodeJS or later version in your machine before starting to work on this project.

# How to run this application
To run this application, you need to first clone the getting-started-with-the-react-rich-text-editor component repository and then open it in Visual Studio Code. Now, simply Build and run your project using the npm run dev command to view the output.
